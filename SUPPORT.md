# Support

For help with a SWIR project, first check the project's README, releases, open issues and documentation.

## Use an issue when

- you found a reproducible bug,
- a documented feature does not work,
- you have a concrete feature request,
- the documentation is incorrect or incomplete.

## Before opening an issue

Please include the project version, operating system, exact steps, expected result, actual result, and logs/screenshots when useful.

Do not post passwords, API keys, access tokens, private addresses or other sensitive information.

For security vulnerabilities, follow the repository's `SECURITY.md` instead of opening a public issue.
