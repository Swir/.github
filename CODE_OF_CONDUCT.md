# Code of Conduct

SWIR projects are intended to be constructive, practical and welcoming technical spaces.

## Expected behavior

- Be respectful and focus criticism on ideas, code and behavior.
- Give useful technical feedback.
- Assume good intent while still asking for evidence when needed.
- Respect different experience levels and communication styles.
- Keep discussions relevant to the project.

## Unacceptable behavior

Harassment, threats, targeted insults, discriminatory abuse, deliberate disruption, spam, doxxing, or publishing another person's private information are not acceptable.

## Maintainer responsibility

Maintainers may edit, remove or reject contributions and interactions that violate these standards. Repeated or serious abuse may result in restricted participation.

## Scope

These expectations apply to project repositories and other official project spaces.
